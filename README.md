# WhatsApp Chat

Веб-чат для отправки и получения текстовых сообщений в WhatsApp через GREEN-API.

## Веб-версия

https://shakh9.github.io/whatsapp-chat/

## Локальный запуск

### 1. Клонировать репозиторий

```bash
git clone https://github.com/Shakh9/whatsapp-chat.git
```

Перейти в директорию проекта:

```bash
cd whatsapp-chat
```

### 2. Установить зависимости

```bash
npm install
```

### 3. Настроить GREEN-API

Создать в корне проекта файл `.env`:

```env
VITE_GREEN_API_URL=ваш_apiUrl
```

Вместо `ваш_apiUrl` необходимо указать `apiUrl` из личного кабинета GREEN-API.

Для работы приложения также потребуется авторизованный GREEN-API instance.

### 4. Запустить приложение

```bash
npm run dev
```

После запуска открыть адрес, который будет указан в терминале.

### 5. Подключиться к GREEN-API

В приложении необходимо указать:

- `idInstance`;
- `apiTokenInstance`.

После успешного подключения можно указать номер телефона собеседника и начать обмен текстовыми сообщениями.
