# WhatsApp Chat

Веб-чат для отправки и получения текстовых сообщений в WhatsApp через GREEN-API.

Перед запуском создайте в корне проекта файл `.env` и укажите `apiUrl` из личного кабинета GREEN-API:

```env
VITE_GREEN_API_URL=ваш_apiUrl
```

Установите зависимости:

```bash
npm install
```

Запустите приложение:

```bash
npm run dev
```

После запуска приложение попросит указать `idInstance` и `apiTokenInstance` из личного кабинета GREEN-API.

После подключения можно указать номер телефона собеседника и начать обмен текстовыми сообщениями.
